# 00 · 最初的想法与实现目标

## 一、最初的想法

> 通过几句话让 LLM 自己深度调研资料，或者喂给它现有的各种资料——比如现有的 PPT 参考、现有的 txt / Word 文档、图片、网页、PDF 各种格式——来创建一个 PPT。生成之后可以有可视化前端逐个页面去调整。全部用 agent，各种 agent。

这段话是这个项目的起点，原样保留。下面是把它拆开之后的具体含义。

### 想解决的痛点

现在市面上的 AI PPT 工具（无论开源闭源）绝大多数只做**一次性生成**：给个主题，吐一份 deck，然后就改不动了。想微调样式、换个图、把某一页重排，要么回去改 prompt 整份重来，要么导出到 PowerPoint 里手动改——AI 那部分的价值到此为止。

我们要的是**生成之后还能继续用 AI 改**，而且改的粒度要到单个元素。

### 两种输入模式

**模式一 · 一句话起手**
用户只给一个主题或几句描述，系统自己去联网做深度调研，自己找资料、自己判断该讲什么，然后成稿。

**模式二 · 喂资料**
用户手上已经有材料——研报 PDF、Word 文档、一堆截图、几个网页链接、一份想参考版式的旧 PPT——系统把这些吃进去，理解之后成稿。

两种模式可以混用：给几句话 + 三个 PDF + 一份参考 PPT。

## 二、实现目标

拆成五层能力。每一层都要能独立替换，不能糊成一坨。

### 第 1 层 · 摄入

把任意格式的输入变成结构化的、LLM 能用的中间表示。

- **必须支持**：PDF、Word、txt / Markdown、图片、网页 URL、PPTX
- **加分**：Excel、扫描件 OCR、音视频转写
- **难点**：中文文档的版面还原、公式、复杂表格
- **参考 PPT 的特殊处理**：不只是提取文字，要能提取**版式结构**和**视觉风格**供后续复用

### 第 2 层 · 调研

从几句话出发，自主地把一个模糊题目做成有内容的材料。

- 能自己拆解研究问题，而不是照着固定流程跑
- 多轮迭代：搜到的东西能引出下一轮该搜什么
- 有来源可追溯（每个结论能指回出处）
- 能和「用户自带资料」混合——自带资料是事实基础，联网调研是补充

### 第 3 层 · 生成

从材料到成型的幻灯片。

- 大纲规划 → 分页 → 每页选版式 → 填内容 → 配图
- **配图要按需**，不是机械地每页塞一张
- 支持模板式（稳）和自由式（好看）两条路
- **必须有渲染后校验**：生成完渲染成图，检查溢出、重叠、留白异常，发现问题回改

### 第 4 层 · 编辑

可视化前端，逐页调整。

- 真画布：元素可选中、可拖拽、可改属性，不是只能改文本框
- 页面级操作：增删页、调顺序、换版式
- 导出：**真·可编辑 PPTX**（在 PowerPoint 里还能继续改），以及 PDF

### 第 5 层 · 调整

选中一页或一个元素，用自然语言让 agent 改。

- 指令粒度要到「把这个标题缩小两号」「这页太挤了帮我重排」「这张图换成饼图」
- 改的是**已有页面**，不是重新生成
- 改完的结果要能立刻在画布上看到

### 贯穿全局 · 多 agent

不是一个大 prompt 干所有事。至少要有：调研 agent、规划 agent、单页生成 agent、审查/反思 agent、编辑 agent。各自可以绑不同的模型。

## 三、验收标准

MVP 跑通的定义，按优先级排：

1. **闭环能跑通** — 输入几句话 → 出一份 PPT → 在前端里选中某个元素 → 说一句话 → 元素被正确改掉 → 导出的 PPTX 在 PowerPoint 里能继续编辑
2. **喂资料这条路能走** — 至少 PDF 和 Word 两种格式，内容确实被用上了而不是被忽略
3. **成品率能看** — 随机生成 10 份，排版不崩的比例要能接受（这一条最难，取决于第 3 层的渲染后校验做得怎么样）
4. **调研有深度** — 一句话起手的产出，内容质量明显好过直接问一次 LLM

暂时不做的：实时协作、演讲者模式、配音视频、移动端。

## 四、几条硬约束

| 约束 | 说明 |
|---|---|
| **模型可换** | 必须能接自己的 key，能用国内模型，能用 Ollama 本地模型。不接受锁死某一家 |
| **可自托管** | 数据不出自己的机器（除了主动调的模型 API） |
| **许可干净** | 优先 Apache-2.0 / MIT。AGPL 的项目要么绕开，要么明确接受开源义务 |
| **中文优先** | 中文排版、中文文档解析是第一优先级，不是「以后再说」 |
